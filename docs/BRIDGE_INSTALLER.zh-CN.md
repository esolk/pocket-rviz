# 在手机内安装 ROS1 bridge（0.3.0）

本功能使用手机上的原生 SSH 客户端操作用户指定的 ROS 主机。查看器协议仍为 Foxglove WebSocket v1，不是 rosbridge JSON。支持范围先限定为 Ubuntu 20.04 / ROS Noetic / amd64 或 arm64；不会安装完整 ROS、混用系统发行版或悄悄退回源码编译。

## 操作流程

1. 在查看器打开“安装 bridge”，输入目标 IP（或域名）、SSH 端口、非 root 用户名。可以用密码，或选择/粘贴 OpenSSH/PEM 私钥及口令。向管理员或主机本机核对显示的 SHA256 主机密钥指纹后继续。
2. 登录后检测系统、架构、ROS 与 bridge。已有 bridge 时提供启动入口；没有时从目标主机现有的 APT 元数据取得主包及所有缺失依赖的下载计划。手机显示包数量和流量大小，由用户确认下载，上传安装另行确认。
3. 手机使用自身当前网络下载 `.deb`，逐包验证大小与 SHA256，再通过 SFTP 传至目标主机的会话缓存目录。Wi-Fi 下载失败时提示用户手动切换移动网络并重新检测重试，应用不切换系统网络，也不保证所有手机支持同时移动数据下载和机器人 Wi-Fi。切网可能使 SSH 断开。安装页面保留非敏感的下载计划与已校验包，允许不连 SSH 的“仅手机下载 / 重试下载”；下载完切回主机 Wi-Fi，重新输入一次性凭据登录，复核同一主机密钥、用户/目标和新包清单后才上传。不同目标或不同清单会清理旧缓存重新下载。退出安装页面则清除本次缓存。
4. 安装时需要目标用户具有 sudo 权限。可填写独立 sudo 密码；免密 sudo 可留空。通过 SSH stdin 提交，执行 `apt-get --no-download --no-remove` 安装已传输的本地包。目标不会由此再次下载软件包；但系统已有 APT hooks 和软件包 maintainer scripts 的行为由主机系统及包决定，不能承诺它们绝不联网或绝不影响服务。
5. 安装完成后再次确认启动。bridge 只监听 SSH 连接到达的具体主机网卡 IP 的 8765 端口，禁用客户端发布、参数操作、服务调用和资源读取，不创建开机自启、不修改防火墙。必须已有可访问的 ROS master；安装器不启动 ROS master。只在可信隔离局域网使用明文 WS。
6. 主机端启动核验成功后，可点击“返回查看器并连接”，自动填入已认证 SSH 主机的 8765 地址并由查看器发起连接，无需复制地址。启动检查会在主机侧验证 Foxglove WebSocket 握手和空 capabilities，只能说明主机侧服务正确；手机侧可达性和话题接收仍必须由查看器验证。

## 凭据与数据

SSH 密码只通过加密 SSH 发给指定目标；私钥仅在手机内用于签名。密码、私钥、口令和 sudo 密码不上传到开发者服务器，不保存到偏好、文件或系统恢复状态，不用于遥测。关闭页面、取消、进入后台时清除表单及会话凭据。Java/Android 内存的垃圾回收意味着不能承诺所有临时字符串在物理内存中即时擦除。页面禁截屏、禁自动填充；用户主动选择的原私钥文件不受删除影响。

主机密钥只在当前页面会话内记住，关闭后清除。每次新页面必须重新核对；当前会话内检测到密钥变化会拒绝连接，不提供忽略验证开关。SSH MFA/交互式认证暂不支持。

下载器只接受官方 ROS/Ubuntu 域名的包地址，拒绝重定向到其他域名或 HTTPS 降级；HTTP 包内容必须匹配经 SSH 取得的可信 APT SHA256。手机不自行实现 OpenPGP 验签：信任根是目标系统已认证的 APT 索引和核对过的 SSH 主机身份，不应把这说成手机独立验证官方签名。目标必须具备可用的可信索引和 python3-apt；显式 Trusted / Allow-Insecure / Allow-Weak 等源覆盖以及全局绕过认证的配置会被拒绝。没有索引或缺可用包时明确失败，不自动改源、导入密钥或通过目标网络更新索引。

## 中断与恢复

- 下载缓存只在手机应用私有缓存，下载失败保留已校验完整包供切网重试，退出安装页面清理；目标成功安装后清除已传 DEB，失败会话缓存与清单保留以便排错，不含凭据。
- 取消/失联不等于回滚。APT 可能已安装了一部分包，bridge 启动可能已经生效。界面提示状态未知，禁止无条件重试；重新连接后先检测。
- 不自动停止现有 bridge，不抢占已有 8765 监听，不删除未知进程或改已有 launch 文件。
- 需要自定义 ROS overlay、不同 ROS_MASTER_URI、TLS、公网访问或其他发行版时，交由管理员明确配置，不静默推测。

## 版本依据与验证范围

ROS Noetic 官方最后发布的 Foxglove bridge 为 0.8.4-1。目标 APT 元数据决定具体架构构建版本及依赖；不硬编码临时 `.deb` URL。ROS1 已结束官方支持，旧二进制不等于不支持本查看器的 PointCloud2/TF/图像订阅，但不宣称获得持续安全更新。

- 官方发行索引：https://github.com/ros/rosdistro/blob/master/noetic/distribution.yaml
- 官方构建状态：https://repositories.ros.org/status_page/ros_noetic_default.html?q=foxglove_bridge
- 0.8.4 launch：https://github.com/foxglove/ros-foxglove-bridge/blob/0.8.4/ros1_foxglove_bridge/launch/foxglove_bridge.launch

本轮合成测试覆盖格式/信任拒绝、系统检测、缺包、校验失败与安装阶段契约。没有在用户机器人安装，也没有物理 Android + Ubuntu Noetic 真实端到端验收。源码测试、APK构建成功不代表真实网络、SSH密钥格式、sudo策略及ROS硬件兼容均已验证。
