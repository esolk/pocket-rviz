# v0.2.0：选择话题与配置显示

## 使用步骤

1. 连接 ROS1 Foxglove bridge，打开左上角图层抽屉。首次连接只订阅 TF；其他话题需要勾选。
2. 在搜索框输入话题名或类型，如 `/lidar`、`PointCloud2`；也可切换到已选、可视化、点云/扫描、图像。
3. 勾选需要的话题。取消勾选立即停止该订阅。搜索仅过滤列表，不会改变已有订阅。
4. 点击该话题右侧 ⚙，调整此图层的显示；更改立即生效并在设备本地保存。关闭设置不撤销更改，「恢复默认」只重置当前图层外观。
5. 固定坐标系与 TF 坐标轴开关在「场景设置」中。缺失 TF 时仍会隐藏无法正确定位的数据。

## 点云设置

- 自动：依次优先使用有效 RGB/RGBA、强度、消息坐标系 Z 高度。
- RGB/RGBA：使用 packed `rgb` 或 `rgba`，支持单值 INT32、UINT32、FLOAT32。消息 alpha 仍忽略，整体透明度在面板设置。
- 强度：使用单值 `intensity`，按本帧有限采样范围归一化；恒定值使用中间灰度，非有限值使用备用颜色。
- 高度：按消息坐标系 Z 的本帧范围着色，不是固定坐标系的高度。
- 固定颜色：整片点云使用所选颜色。显式 RGB/强度字段缺失或无效时也用此备用色，状态会说明原因。
- 点大小：0.01–0.5 米，随距离缩放。
- 不透明度：0–100%，0 表示完全透明。
- 上限：每个点云独立选择 2 万、6 万、12 万点/帧，采用索引等距采样，不是体素滤波。

扫描可调整颜色、点大小、不透明度；路径和姿态可调整颜色、不透明度；地图可调整不透明度；Marker 的不透明度乘以消息原有 alpha，消息颜色与形状保留。图像话题可以通过「显示此图像」切换当前浮动图像面板；未订阅时按钮仅提示订阅，不偷偷启动数据流。

## 保存与限制

- 以服务器 URL、话题名称和消息类型保存，重连后 channel ID 变化不会串用其他图层设置。同名不同类型分开保存，离线演示也分开保存。
- 最多 12 个服务器，每个 256 个话题，序列化上限 1,500,000 字符。最旧服务器/图层在超限时被逐出。
- 含 URL 查询参数的连接只在当前会话保留设置，避免保存认证参数。关闭浏览器存储或空间不足时，会提示保存不可用，当前会话可继续使用。
- 点云颜色模式/预算变化会重解码已缓存最新消息。缓存已被资源上限逐出时，旧几何清空，等待新消息；不会为刷新设置额外重订阅或伪造新数据。
- 仍只有 subscribe/unsubscribe；不发布 ROS 数据、不调用服务、不修改参数。最多 32 个并发订阅，TF 也计入。

## 安装提示

这次单独交付的 v0.2.0 测试 APK 使用新的调试签名，不能覆盖先前的 v0.1.1 APK。需要先记录连接地址等本地设置，再自行卸载旧版、安装新版；卸载会删除本地偏好。源码构建使用你自己的本地密钥，今后应保留该密钥以便覆盖更新。

## 验证边界

新增解码、Three 对象、订阅、偏好和 DOM/event 回归测试。此次未完成物理 Android 安装、真实 GPU/触控或真实 ROS 机器人验收。800×360 和 915×412 的布局设计包含独立滚动列表、可滚动设置面板及 48px 主要按钮；实际屏幕、键盘与触摸仍需要实机检查。
