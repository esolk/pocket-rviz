# 验收清单：7 英寸手机横屏 ROS 查看器

主目标是 7 英寸手机横屏；CSS 视口优先检查 915×412 和 800×360，兼顾 412×915 竖屏回退。英寸与 CSS 像素没有一一对应关系，最终要在实际机型上检查系统缩放、WebView 版本和刘海/挖孔区域。

## 测试层级与证据

明确区分：

1. 独立 Python 合成消息测试：可以验证协议包/字段/预期结果。
2. 桌面 Chromium 浏览器测试：可以验证页面连接、渲染和响应式 UI。使用软件渲染或设备模拟时必须标明。
3. Android APK 测试：需要真实 APK 安装到真机/模拟器；桌面截图不能冒充。
4. 真实 ROS1 系统对照：使用测试 Jetson、固定版本桥接器、受控 rosbag 或发布节点，与 RViz 比较。合成数据不能代替。

公开源码的实际复核状态见 `VALIDATION.zh-CN.md`。未运行的项目不可打勾。

## 交互与小屏布局

- 横屏 915×412、800×360 下主要画布不被固定侧栏/状态栏挤没；主要按钮触控区建议至少 48 CSS px。
- 话题抽屉打开、关闭、再次打开、快速重复切换均不遗留遮罩；点击遮罩和返回键行为合理。
- 摄像机俯视/透视/重置按钮可以触控；单指旋转、双指平移/缩放不误触网页滚动。
- 横竖屏切换后画布尺寸更新、按钮可见、页面无横向溢出，连接和订阅不被意外重置。
- 顶栏、抽屉、底部工具避开安全区域；真实系统导航条/刘海不盖住连接、断开和关闭按钮。
- 连接输入在软键盘弹出时仍可操作；返回键先收键盘/抽屉，再按产品定义退出，不能卡住。
- 字体在实际 7 英寸屏上可读；不只看电脑截图。

## 协议与只读边界

- 握手子协议为 `foxglove.websocket.v1`；收到 serverInfo 和 advertise 后才显示真实话题。
- 勾选图层产生 subscribe；取消产生 unsubscribe；断开释放连接；重复连接不会累计 WebSocket 或订阅。
- 审计服务端实际入站日志：仅有订阅/取消订阅，不出现发布、参数写入、服务调用或其他控制指令。
- 服务端撤销话题、重新广告、重启和网络丢失有清楚状态；不会把合成演示标为真实连接。
- 错误 schema、损坏/截断二进制帧和不支持消息类型可诊断，不造成整页崩溃。
- 在 Android 壳完全相同的 CSP 下测试消息解析。`script-src 'self'` 不允许 `new Function`/eval，不能只验证 Vite 开发页。

## 可视化与数值检查

### PointCloud2

- 检查不同字段排列、FLOAT32/FLOAT64/整数坐标类型、点内填充、行填充、大小端、NaN/Inf。
- 合成混合类型点云 2×3，point_step=24，row_step=80，160 数据字节；应显示 5 个有限坐标点，不能把行填充解为点。
- 颜色字段 uint32 RGB 和强度映射正确；限点策略必须标明，禁止凭丢点后的数量声称完整数据。
- 实测目标点数/频率、CPU/GPU、内存、温度和端到端延迟，并记录机型。未测试不能承诺帧率。

### TF

- map → base_link → lidar 多级组合；本样例初始 base=(2,1,0)、yaw=90°，lidar offset=(0.5,0,0.25)。局部点 (x,y,z) 应变为 (2-y,1.5+x,z+0.25)。
- `/tf_static` 常驻；动态 TF 按消息时间查询而非仅取最新。移动底盘下的历史消息与 RViz 对齐。
- 缺失 TF、超出缓存时间、重复/乱序样本、仿真时钟回退、重连到不同机器人时有明确处理。

### 地图、路径、标记、图像

- OccupancyGrid：16×16、0.5m 分辨率、原点 (-2,-2,0)，占据/空闲/未知格区分；另测旋转原点。
- Path：15 个 poses 顺序连线，使用消息/pose header frame 和时间。
- Marker：命名空间+ID 区分对象，ADD/MODIFY、DELETE、DELETEALL、lifetime、frame_locked 按已声明支持范围验证。样例 ADD 两个 ID 7、8；删 7 后只剩 8；DELETEALL 后清空。
- CompressedImage：本样例 320×180 JPEG，图上有 SYNTHETIC QA 标记；显示比例正确。另测 PNG、损坏图片和格式变化。
- 未实现的显示类型、URDF、RViz 原生 C++ 插件和 .rviz 配置导入应明确提示。ROS 消息兼容不能等同 RViz 插件二进制兼容。

## Android 与现场测试（必须另行执行）

- 安装 APK；记录签名类型、包名、versionCode、Android/WebView 版本和设备型号。
- 断互联网后本地 UI 仍可启动；连接机器人局域网才接收实时话题。
- 网络切换、息屏/恢复、进入后台/返回、连续使用 30–60 分钟和低电量策略下无失控队列/泄漏。
- 可信 WSS 成功；错误证书失败且不可自动绕过；无意外摄像头/麦克风/定位权限申请。
- 真实桥接只读配置验证，测试 rosbag 与桌面 RViz 对照截图和时间戳。生产机器人必须遵循现场变更、安全和网络审批流程。
